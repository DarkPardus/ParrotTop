ParrotTop is a terminal-based system monitoring tool running on Parrot Security OS.
It provides real-time system information through a clean and detailed interface, including CPU usage, memory, disk activity, network traffic, power consumption and running processes.
A lightweight and practical way to monitor system performance directly from the terminal.
Security. Performance. Control.


ParrotTop, Parrot Security OS üzerinde çalışan terminal tabanlı bir sistem izleme aracıdır.
CPU kullanımı, bellek, disk etkinliği, ağ trafiği, güç tüketimi ve çalışan işlemleri gerçek zamanlı olarak, sade ve detaylı bir arayüz üzerinden takip etmenizi sağlar.
Sistem performansını doğrudan terminal üzerinden izlemek için hafif ve kullanışlı bir çözüm.
Güvenlik. Performans. Kontrol.
